# OneTake公众号影视类文章标题skill

为一分钟治片慌（OneTake）的公众号的文章、选题等内容取标题，所需的标题一句话概括就是：

**"看了就想点开。"**

## 标题核心设计原则

**最终目标**：标题让读者忍不住想点开、看完、刷评论、转发安利的冲动。必须至少有情绪、争议和共鸣三大核心的其中一个。

**核心原则**：

- 抓住共同情绪精准捕捉读者的愤怒、破防、意难平、狂喜、被虐或“终于有人说出来了”的情绪（如“为什么所有热播剧都要虐CP？”“看完《XXX》我整夜睡不着”“这部剧把我的青春毁完了”），让标题一秒击中读者的心。

- 留出讨论与共鸣空间，标题不剧透、不说满，暗示“内有深度分析/避雷/彩蛋”，引导读者点开后忍不住在评论区刷屏讨论、吐槽或安利。

- 足够具体+强画面感用具体剧名、场景和细节制造代入感（如“刷完《庆余年2》第5集后，我对范闲的滤镜彻底碎了”“《黑神话》上线后，我连夜二刷才发现这个细节”），让标题自带画面。

- 带轻微争议或反常识（如“大家都说这部剧神作，但我看完只想说3个字”“别再吹《XXX》了，它最大的问题其实是……”“2025最被高估的3部剧”），轻松引发争议和讨论。

- 让读者想展示自己，让读者看完后愿意留言“我也这么觉得”“补充一个更离谱的细节”“我比你早看三集”。

- 能引导转发与收藏标题同时兼顾“追剧实用价值”和“社交货币”，让读者愿意转发给朋友或收藏（如“转给还在熬夜追剧的你”“每个剧迷都该收藏这篇”）。

- 能击中目标读者身份精准对标影视受众身份（如重度剧迷、韩剧粉、国产剧粉、悬疑爱好者、电影发烧友、CP党），制造“这是写给我们追剧人的”的强烈归属感。

### 用词选择标准

- 有吸引力：如“反乌托邦”、“特种作战教科书”、“史前文明”等
- 非常规用词，思考标题每一个词，是否有可替换的不常见的词汇：如“1+1=1”等

### 输出格式

30字以内

### 禁用词

- "最狠"
- "扎心"

### 目标受众

- 36-65岁


## 参考指南

### 标题公式结构

#### 公式 1：反差悬念型

- 标题结构：【极端对立现象/标签】 + 【核心主体】 + 【悬念疑问词/反常结果】
- 例句说明该结构的具体用法：**《被男女共同抵制，她新片还是9.2》**。先抛出"男女共同抵制"的负面极端现象，紧接"9.2分"的极高口碑反常结果，强烈的矛盾感逼迫读者点击探究原因。
- 同理如 **《又黄又搞笑又恐怖，他怎么做到的》**

#### 公式 2：情绪共鸣型

- 标题结构：【社会痛点/大众情绪】 + 【犀利论断/感叹句式】
- 例句说明该结构的具体用法：**《国产恩爱CP，演不下去了》**。直接点出观众苦"工业糖精"久矣的痛点，用"演下去了"表达犀利批判
- 或者如 **《这「少儿不宜」，18岁以上也得禁》**，用强烈的站队和抵制情绪引发群体共鸣

#### 公式 3：数据权威型

- 标题结构：【打破纪录的数据/炸裂评分】 + 【引发该成绩的核心看点/受众反馈】
- 例句说明该结构的具体用法：**《分数还在涨，他越骚观众越爱》**。用"分数还在涨"确立作品的高品质基调，用"越骚越爱"勾勒出角色的核心魅力，吸引对高分爽剧感兴趣的受众
- 同理如 **《刚第二集，完全是剧王水平》**

#### 公式 4：趋势洞察型

- 标题结构：【具体现象/作品动作】 + 【行业震动/宏观结论】
- 例句说明该结构的具体用法：**《这下，明星综艺凉凉》**。从近期几个综艺的低迷，直接下达"明星综艺凉凉"的行业死亡判决
- 同理如 **《这飞升速度，内娱谁看了不羡慕》**，从春节档短剧爆火直接点出内娱新风向
