# Viral-longform-zh: 爆款长图文创作公式指南

> **方法论来源**：基于 MECE（相互独立、完全穷尽）原则，把"爆款长图文"拆成 6 大独立模块 × 4 个公式 = **24 个可复用创作公式**。
> 公式与示例综合自公众号长图文领域头部账号作品（含 Sir电影 等）的爆款拆解分析。

---

## 项目简介

Viral-longform-zh 是一个**纯公式库型** skill：它不替你写文章，而是给你 24 个明确可命名的"爆款公式"，让写公众号长图文（影评、剧评、社会观点文、盘点前瞻文、人物稿等）这件事变成"按公式填空"。

适合：

- 公众号运营 / 自媒体写手：写影评、剧评、人物稿、行业观察
- 影视从业者：写宣传稿、深度长评、年度盘点
- 内容编辑：给已写好的长文做结构诊断与改稿优化

## 6 大模块速览

| # | 模块 | 4 个公式 | 核心作用 |
| --- | --- | --- | --- |
| 一 | 标题 | 反差悬念 / 情绪共鸣 / 数据权威 / 趋势洞察 | 决定点击率 |
| 二 | 开篇 | 场景互动 / 反常识切入 / 定性宣判 / 数据现象 | 决定留存率 |
| 三 | 全文结构 | 影视测评 / 人物分析 / 社会观点 / 盘点前瞻 | 决定骨架 |
| 四 | 分模块 | 小标题递进 / 案例论证 / 金句嵌入 / 节奏控制 | 决定肉感 |
| 五 | 结尾 | 价值升华 / 行业号召 / 情感共鸣 / 留白拷问 | 决定转发沉淀 |
| 六 | 配套要素 | 排版视听化 / 人设强化 / 金句高亮 / SEO 混搭 | 决定视觉传播 |

## 使用

### 基础用法

#### 1. 直接调用技能

```
/viral-longform-zh 帮我按公式写一篇关于《XXX》的影评
```

#### 2. 在对话中使用

```
我想写一篇春节档短剧盘点文，请按 viral-longform-zh 的公式帮我搭结构。
```

#### 3. 对现有长文做结构诊断

```
/viral-longform-zh 帮我看一下这篇长文的标题和开篇，按公式该怎么改？
```

### 创作流程示例

**任务**：写一篇"某烂剧批判"的公众号长图文

1. **定类型** → 模块三公式 1：影视/现象测评文
2. **选标题** → 模块一公式 2：情绪共鸣型 → 例：《国产XX，演不下去了》
3. **选开篇** → 模块二公式 3：定性宣判型 → "Sir 三字开场：'没救了。'"
4. **搭骨架** → 模块三公式 1：表层观感 → 深层拆解 → 行业升华
5. **分模块打磨** → 模块四 4 项全用：
   - 小标题递进：01 悬浮 → 02 失真 → 03 傲慢
   - 案例论证：复述剧中荒诞台词 + 犀利反问
   - 金句嵌入：拔高一句"**真正的现实主义从不靠拉踩普通人造梦**"
   - 节奏控制：用"停、停、停。"切断长段
6. **选结尾** → 模块五公式 2：行业号召型
7. **配套要素** → 模块六 4 项全用（短句分行 / "Sir"自称 / 金句加粗 / 流行语+高级词混搭）

## 选题 → 结构速查表

| 选题类型 | 推荐结构（模块三） | 推荐结尾（模块五） |
| --- | --- | --- |
| 单部剧/电影评测 | 公式 1：影视/现象测评文 | 公式 2（烂剧批判）或 公式 3（年度佳作致敬） |
| 演员/导演人物稿 | 公式 2：人物演技分析文 | 公式 1（向内求索）或 公式 3（致敬） |
| 借影视事件讲社会议题 | 公式 3：深度社会观点文 | 公式 4（留白拷问） |
| 多部剧盘点 / 年度前瞻 | 公式 4：盘点前瞻干货文 | 公式 2（行业号召） |

## 使用建议

1. **6 大模块顺序不要乱**：标题 → 开篇 → 结构 → 分模块 → 结尾 → 配套要素，每步都可能反向影响前一步选择
2. **每个模块只选 1 个公式**，但分模块（4）要 4 项全用（小标题/案例/金句/节奏一个都不能少）
3. **配套要素（6）建议全部落地**，是公众号长图文区别于纯文字稿的关键
4. **公式可叠加但不可冲突**：例如标题用"反差悬念型" + 开篇用"反常识切入型"是天然搭配，但 + 结构用"盘点前瞻文"就自相矛盾
